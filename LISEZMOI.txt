IMPORTANT — modules.json
------------------------
  factory/modules.json est la configuration du POSTE (chemins Windows).
  Un fichier PRÊT POUR LE SERVEUR est fourni : factory/modules.json.serveur-exemple
  Sur le serveur :
    1) remplacer le domaine outils.adbi.fr par le vôtre dans ce fichier,
    2) puis :  mv modules.json.serveur-exemple modules.json
  (Détails : guide, section 6.)

CE QUE LE PAQUET NE CONTIENT PAS (volontairement)
-------------------------------------------------
  - Le module ADBI Gestion (gestion_esn) : EXCLU du déploiement, reste interne.
  - Les node_modules : à installer sur le serveur (guide, section 5 : npm ci).
  - Les secrets et clés du poste (secrets.json, clé du Coffre, jwt) : les clés
    API se saisissent dans l'interface après déploiement (guide, section 10) ;
    le Coffre génère SA propre clé au premier usage (guide, section 11).
  - Les données de travail du poste (contrats enregistrés, CV, documents) :
    la plateforme démarre à vide. Le référentiel clients (contrats/data/
    referentiels.json) est fourni, lui, car utile à toute l'équipe.
