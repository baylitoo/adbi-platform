========================================================================
  ONE PAGER — générateur de dossiers de compétences ADBI
========================================================================

À QUOI ÇA SERT
--------------
Vous importez un CV (PDF, Word ou texte), quelle que soit sa mise en page.
L'outil en extrait les informations, vous les fait valider, puis génère un
dossier de compétences sur UNE SEULE PAGE au format ADBI.


DÉMARRER
--------
Double-cliquez sur l'icône « One pager » sur le Bureau.
Une fenêtre noire s'ouvre : LAISSEZ-LA OUVERTE pendant l'utilisation.
Le navigateur s'ouvre tout seul sur http://localhost:4200

Pour arrêter : fermez la fenêtre noire.

Si le raccourci a disparu : clic droit sur « Creer-Raccourci-Bureau.ps1 »
dans ce dossier, puis « Exécuter avec PowerShell ».


LES TROIS ÉTAPES
----------------
1. IMPORT
   Glissez le CV dans la zone, ou cliquez sur « Choisir un fichier ».
   Formats acceptés : .pdf, .docx, .txt   —   20 Mo maximum.
   Un PDF scanné (image) ne peut pas être lu : réexportez-le en PDF texte.

2. VALIDATION
   Le texte lu est affiché à gauche, les champs extraits à droite.
   Tout est modifiable. Les champs incertains sont encadrés en orange.
   C'est l'étape importante : aucune extraction automatique n'est fiable
   à 100 %, mais la corriger prend quelques secondes.

3. ONE-PAGER
   Aperçu en temps réel. Réglages disponibles :
     - Anonymisation (trigramme par défaut) :
         Trigramme   « MDI : Chef de projet IT » — initiale du prénom
                     + 2 lettres du nom. Modifiable dans le champ juste
                     en dessous si le trigramme interne diffère.
         Nom complet « Mamadou DIALLO : Chef de projet IT »
         Code client pour imposer un code au lieu du trigramme
     - Densité : compacte, normale, aérée
     - Angle : neutre, technique, management
     - Nombre de missions affichées
     - « Cibler une offre » : collez une fiche de poste, le classement
       des missions et des réalisations s'adapte au besoin du client.

   Le panneau « Écarté du one-pager » liste tout ce qui a été retiré et
   pourquoi. Cliquez sur une mission pour la réintégrer.

   Exports :
     - Imprimer / PDF  : impression navigateur (choisir « Paysage »)
     - PowerPoint      : fichier .pptx retouchable
     - JSON            : données structurées complètes


IMAGES (portrait, badges, vague, logo)
--------------------------------------
Tout est déjà extrait du livret PowerPoint ADBI, dans public\assets\ :

  fond-vagues.svg/.png  la vague d'arcs orange du gabarit
  coin-orange.svg/.png  le coin orange du pied de page
  logo-adbi.png         le logo couleur (aperçu écran)
  logo-adbi-blanc.png   le logo blanc posé sur le coin orange (PowerPoint)
  avatar-*.png          4 illustrations (3 hommes, 1 femme)
  badges\badge-*.png    21 logos de certification (Power BI, PSM, Talend,
                        AWS, Qlik, Scrum...)

Dans l'écran 3, vous pouvez :
  - importer une VRAIE PHOTO : elle est recadrée dans le cercle orange,
    quelles que soient ses proportions ;
  - ou choisir une illustration si vous n'avez pas de photo ;
  - cocher jusqu'à 5 badges de certification affichés en bas de page,
    ou importer une image de badge qui ne serait pas dans la liste.

POUR AJOUTER DES IMAGES À DEMEURE
  - un badge   : déposez le fichier dans public\assets\badges\
  - un avatar  : déposez un PNG nommé avatar-quelquechose.png dans
                 public\assets\  (format carré, 512x512 conseillé)
  - la vague ou le logo : remplacez fond-vagues.svg ou logo-adbi.png
Rafraîchissez la page, ils apparaissent dans les galeries.

Si vous ajoutez ou remplacez une image au format SVG (avatar, vague,
coin orange), lancez ensuite :
    node scripts\build-assets.js
puis ouvrez l'adresse indiquée. Cela crée la version PNG, indispensable
car PowerPoint n'affiche pas correctement le SVG.

L'export PowerPoint reprend le gabarit du livret ADBI au point près :
slide 20 x 11,25 pouces, vagues d'arrière-plan pivotées (336° en haut à
droite, 146° en bas à gauche), coin orange et logo blanc en pied. Ces
éléments sont FIXES : ils ne dépendent d'aucune donnée du CV.
Les corps de police suivent également le livret : 27 pt pour les
bandeaux, 21 pt pour l'ancienneté, 18 pt pour les pastilles, 15 pt pour
le texte des missions.


HISTORIQUE
----------
Onglet « Historique » en haut à droite. Chaque CV validé y est enregistré
avec son trigramme, son titre, son nombre de missions et son fichier
d'origine.

  - la recherche porte sur TOUT le contenu : un nom, une techno, un
    client (« snowflake », « AP-HP », « Talend »...) ;
  - un clic sur une ligne rouvre le CV à l'étape Validation, sans
    réimporter le fichier ;
  - la croix retire l'entrée de l'historique (le fichier d'origine
    n'est pas touché).


CONFIDENTIALITÉ
---------------
Tout fonctionne en local sur ce poste. Aucun CV n'est envoyé sur Internet.
Les données sont dans le fichier data\cvs.sqlite de ce dossier.


ORGANISATION DU CODE
--------------------
  server.js              serveur web + points d'entrée de l'API
  lib\ingest.js          lecture PDF/DOCX/TXT, détection des colonnes
  lib\layout.js          découpage en sections (profil, expériences...)
  lib\extract.js         extraction des champs -> cv_master
  lib\normalize.js       dates, téléphones, niveaux de langue
  lib\taxonomy.js        référentiel de 312 technologies et leurs alias
  lib\score.js           priorisation des missions et des réalisations
  lib\onepager.js        réduction à une page (budgets, gabarit)
  lib\render-pptx.js     export PowerPoint
  lib\db.js              base locale SQLite
  public\                interface (index.html, app.js, styles.css,
                         onepager.css = le gabarit imprimé)

Deux niveaux de données, volontairement séparés :
  - cv_master   : extraction complète, sans perte, stockée et éditable
  - cv_onepager : projection réduite, recalculée à chaque affichage
Changer de gabarit ou de cible ne nécessite donc jamais de réimporter.


PRÉREQUIS
---------
Node.js (version LTS) — https://nodejs.org
Les dépendances s'installent toutes seules au premier lancement.
