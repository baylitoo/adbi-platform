Envoyer en signature

Le contrat est figé tel quel puis confié au tiers de confiance (connecteur Yousign, eIDAS) : chaque partie reçoit son invitation par e-mail, relit le document et signe sur la page sécurisée du fournisseur (code de vérification par e-mail). Ordre de signature : le co-contractant signe en premier, ADBI signe ensuite — relances automatiques, puis PDF signé + dossier de preuve récupérés dans le dossier du contrat.

Signature électronique — connecteur API —

La signature passe exclusivement par un tiers de confiance (connecteur API) : il envoie les invitations et les relances, fait signer sur sa page sécurisée, et fournit le dossier de preuve. Deux connecteurs au choix : Yousign (eIDAS 🇫🇷, données UE, clé API simple, sandbox gratuite) et Zoho Sign (région UE possible, OAuth2 — pratique si vous êtes déjà chez Zoho). Voir docs/INTEGRATION-SIGNATURE.md.

📝 Modèles de contrat — modifier le texte

Modifie ici le texte du modèle (articles, titres, en-tête, pied de page) : l'aperçu et tous les exports (PDF, Word, signature) utiliseront ta version. Conserve les variables {{…}} (elles sont remplacées par les valeurs du formulaire) et le gras **…**. Les blocs personnalisés sont marqués et réversibles un par un (↺). Évite de modifier un modèle pendant qu'une demande de signature est en cours (le document régénéré changerait).
